Сюда кладутся PDF-каталоги для скачивания.

1. Скопируйте файл в эту папку, например:  mebel-2026.pdf
2. Откройте src/data/catalogs.js и у нужного каталога укажите:
      file:  '/katalogi/mebel-2026.pdf',
      pages: 84,
      size:  '12 МБ',
3. npm run build

Важно: очень тяжёлые файлы (>25 МБ) лучше не хранить в репозитории —
залейте их на хостинг relentgroup.ru и укажите полную ссылку в поле file.
