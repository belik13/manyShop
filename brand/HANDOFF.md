# Handoff: логотип Relent (белый на чёрном)

## Overview
Текстовый логотип (wordmark) «Relent» для тёмного фона. Набран шрифтом сайта —
**Fraunces Regular (400)**, трекинг +0.02em, как в шапке relentgroup.ru.
Во всех SVG текст переведён в кривые: шрифт для открытия файла не нужен.

## Design Tokens
| Токен | Значение | Применение |
|---|---|---|
| `--black` | `#26251f` | фон (тёплый чёрный) |
| `--white` | `#e9e6de` | буквы (тёплый кремово-белый) |
| `--ff-display` | Fraunces 400 | начертание логотипа |
| tracking | `+0.02em` | межбуквенное расстояние |

Пара `#e9e6de` на `#26251f` даёт контраст **12.3 : 1** — WCAG AAA.

## Geometry
- Шрифт: upem 2000, advance width слова — 6276 ед.
- Bounding box букв: 6106 × 1498 ед. (≈ 4.08 : 1)
- Базовая линия: y = 0; выносные (`l`, `t`) — до −1475; свес `e` — +23

## Clear space
Минимальное свободное поле вокруг логотипа — **0.28 × высоты букв**
(≈ 420 ед., в SVG уже заложено). Ничего не размещать ближе.

## Usage
**Можно:** масштабировать пропорционально; ставить на фото при достаточном
затемнении подложки; использовать инверсию на светлом фоне.

**Нельзя:** менять трекинг и пропорции; подставлять другой шрифт; добавлять
тень, обводку, градиент; размещать на пёстром фоне без затемнения;
перекрашивать в цвета вне палитры.
