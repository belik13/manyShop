# Что нужно доработать в базе знаний

Статьи написаны на проверяемых фактах: механика процессов, критерии отбора,
назначение документов. **Конкретных цифр в них намеренно нет** — их нельзя
выдумывать, иначе первый же клиент поймает на несоответствии, а поисковики
и ИИ теряют доверие к источнику.

Ниже — что добавить, чтобы статьи стали сильными. Формат: пришлите фактуру,
я вставлю в текст и пересоберу сайт.

---

## 1. Как выбрать фабрику мебели в Китае
`/baza-znaniy/kak-vybrat-fabriku/`

- [ ] Сколько фабрик обычно в шорт-листе под один проект
- [ ] Сроки производства по категориям: мягкая мебель / корпусная / свет / плитка
- [ ] Реальный случай: фабрика не подошла — по какому признаку это выяснили
- [ ] Минимальный объём заказа (MOQ), с которым обычно работаете

## 2. Как проверить китайского производителя
`/baza-znaniy/kak-proverit-proizvoditelya/`

- [ ] Сколько проверок фабрик проводите в месяц / за проект
- [ ] Случай, когда проверка выявила подмену: торговая компания выдавала себя за фабрику
- [ ] Фото/видео с выездов на производство (сильнее любого текста)
- [ ] Названия 2–3 фабрик-партнёров, которые можно раскрывать публично

## 3. Документы для импорта мебели из Китая
`/baza-znaniy/dokumenty-dlya-importa/`

- [ ] Полный перечень документов по вашей типовой поставке
- [ ] Работаете ли с сертификацией сами или через партнёров
- [ ] Сроки оформления: сколько занимает подготовка комплекта
- [ ] Обезличенный образец комплекта документов (скан с закрытыми данными)

## 4. Из чего складывается стоимость доставки
`/baza-znaniy/stoimost-dostavki/`

- [ ] Порядок ставок: за куб или за контейнер, вилка «от–до»
- [ ] Реальные сроки по видам транспорта: море / ЖД / авто / авиа
- [ ] Размер таможенных платежей по мебели (пошлина + НДС) в вашей практике
- [ ] Пример расчёта по обезличенному проекту: объём → стоимость → срок

## Общее по сайту

- [ ] **Телефон** — поле `phone` в `src/data/site.js` пустое.
      Как заполните — `contactPoint` появится в схеме автоматически.
- [ ] **Отзывы** — материалов пока нет, раздел не делали сознательно
- [ ] **Фото с фабрик и инспекций** — усилят и базу знаний, и раздел «Китай»
- [ ] **Реальные цены** в блоке сравнения (сейчас расчётные −70%)

## Чего делать НЕ надо

- Не заказывать 500 AI-статей: Google прямо предупреждает против массовой
  генерации, Яндекс фильтрует ещё жёстче. Лучше 10–12 сильных материалов.
- Не дублировать темы: логистика живёт только на `/dostavka-nds/`,
  этапы проекта — только на `/kak-rabotaem/`.
